# Blink 视频介绍脚本

> 目标时长：3-4 分钟 | 适合平台：B站 / YouTube / 小红书

---

## 开场（0:00 - 0:20）

**[画面]** 终端全屏，黑底绿字（或 GitHub dark 主题），光标闪烁。

**旁白：**
你的电脑上有多少个 Git 仓库？十几个？几十个？

每次要找一个项目，是不是要 `cd` 来 `cd` 去，或者打开 Finder 一个个翻？

**[画面]** 演示痛点：在终端里反复输入 `cd`、`ls`，打开 Finder 滚动查找。

**旁白：**
今天介绍一个工具，让你在终端里一眼看到所有仓库，键盘操作，秒级定位。

它叫 **Blink**。

---

## 安装与启动（0:20 - 0:40）

**[画面]** 终端输入命令，展示完整过程。

**旁白：**
安装只需要一行：

```bash
pip install blink-repo
```

装好之后，输入 `blink` 回车。

**[画面]** 运行 `blink`，展示首次扫描的加载过程，然后 TUI 界面弹出。

**旁白：**
第一次启动会自动扫描你的主目录，找到所有 Git 仓库。扫描完之后，你会看到这个双栏界面。

---

## 核心功能演示 — 仓库管理（0:40 - 1:50）

### 浏览与状态（0:40 - 1:00）

**[画面]** 在仓库列表中上下移动光标，右侧详情面板实时更新。

**旁白：**
左边是仓库列表，右边是详情面板。用方向键上下移动，右边会实时显示当前仓库的信息：路径、远程地址、分支名、是否有未提交的修改。

**[画面]** 指向列表中的状态徽标，展示 ahead/behind、dirty 等标记。

**旁白：**
注意看列表右侧的小标记——ahead 表示本地领先远端，红色的点表示有未提交的修改。一眼就能看出哪些仓库需要关注。

### 搜索（1:00 - 1:15）

**[画面]** 按 `/` 键，搜索框弹出，输入关键词实时过滤。

**旁白：**
按 `/` 可以随时搜索。支持按名称、路径、标签、描述过滤。比如我只记得项目名里有 "api"，直接搜就行。

**[画面]** 输入 "api"，列表瞬间过滤，只剩匹配的项目。按 Esc 清空搜索。

### 一键操作（1:15 - 1:50）

**[画面]** 选中一个仓库，依次演示快捷键操作。

**旁白：**
选中仓库后，可以一键完成常用操作：

- `Shift+1` — 在终端中打开这个仓库
- `Shift+2` — 用 IDE 打开，支持 VS Code、Cursor
- `Shift+3` — 在 Finder 中显示
- `Shift+4` — 浏览器打开远程仓库页面

**[画面]** 按 `Shift+2`，VS Code 打开对应项目。按 `Shift+4`，浏览器弹出 GitHub 页面。

**旁白：**
`Shift+5` 一键推送，`Shift+6` 一键拉取。不用记 git 命令，一个键搞定。

**[画面]** 按 `Shift+5`，状态栏显示 "正在推送..."，推送成功。

### 个性化标记（1:50 - 2:10）

**[画面]** 按 `Tab` 切到详情面板，展示 Local Markers 区域。

**旁白：**
按 `Tab` 切到右侧，可以给仓库设置置顶、别名、标签和描述。置顶的仓库会排在最前面，加个标签方便分类。

**[画面]** 演示编辑标签，添加 "python" 标签，回到列表看到标签显示在名称旁边。

---

## AI 功能演示（2:10 - 3:10）

### AI 自动提交（2:10 - 2:35）

**[画面]** 退出 TUI，在终端中演示 `blink commit`。

**旁白：**
Blink 还内置了 AI 功能。比如自动提交——在项目目录下运行 `blink commit -p .`，AI 会分析你的代码变更，自动生成 commit message 并提交。

**[画面]** 运行 `blink commit -p .`，展示 AI 生成的 commit message，确认后提交成功。

### AI Code Review（2:35 - 3:00）

**[画面]** 演示 `blink review` 命令。

**旁白：**
更强大的是 AI Code Review。输入 `blink review` 加上同事的分支名，Blink 会自动检出分支、分析变更，输出结构化的审查报告。报告中会标明每个问题的严重程度，最后给出 APPROVE 或 DENY 的结论。

**[画面]** 展示一份 review 报告，高亮问题列表和最终结论。

**旁白：**
也可以在 TUI 里直接按 `Shift+8` 启动 Review，不用记命令。

### 任务编排（3:00 - 3:10）

**[画面]** 简短展示 `tasks.yaml` 和 `blink run`。

**旁白：**
如果你有重复性的开发任务，可以在 `tasks.yaml` 里编排好，用 `blink run` 一键执行。这个功能适合高级用户，有兴趣可以看文档。

总结一下：Blink 是一个终端里的仓库管家。安装即用，扫描自动完成，所有操作键盘搞定，还有 AI 帮你提交代码和做 Review。

**[画面]** 展示安装命令和 GitHub 地址。

## 拍摄提示

- **终端字体**：建议使用等宽字体，字号偏大（确保视频清晰可读）
- **主题**：使用 GitHub dark 或类似暗色主题，录制效果好
- **节奏**：每个操作演示控制在 5-10 秒内，不要停留太久
- **快捷键提示**：可以在画面右下角叠加当前按下的快捷键
- **背景音乐**：轻快的 lo-fi 或电子背景音，音量调低
- **字幕**：建议全程字幕，方便静音观看
