# Plan 3: 快捷键与输入安全重构

> **状态：已完成** — 2025-05-17 实现完毕

## 目标

消除误触——默认状态下按键不触发任何操作，需要 Shift 或进入输入态才能操作。

---

## 变更项

### 3.1 Shift 门控快捷键（列表视图）

**现状**：`j`/`k`/`v`/`u`/`a`/`o`/`y`/`r` 等按键直接触发。

**改为**：

| 操作 | 按键 | 需要 Shift |
|------|------|:----------:|
| 导航上下 | `Shift+↑` / `Shift+↓` | ✓ |
| 打开编辑器 | `Shift+V` / `Shift+U` / `Shift+A` / `Shift+O` | ✓ |
| 复制路径 | `Shift+Y` | ✓ |
| 重新扫描 | `Shift+R` | ✓ |
| 进入详情视图 | `Enter` | ✗ |
| 进入搜索 | `/` | ✗ |

- `j`/`k` **全局删除**，不再作为导航键
- `Enter`（进入详情）和 `/`（进入搜索）**不需要 Shift**，可直接触发
- `e`/`t`（别名/标签编辑）从列表视图移除（这些操作移至详情视图）
- 导航也可使用裸方向键 `↑`/`↓`（作为后备）

**快捷键栏（footer）**：
- 始终显示，但使用非常暗淡的颜色（`fg:#30363d bg:#0d1117`），视觉上不干扰
- 按 Shift+任意快捷键时，短暂高亮 2 秒后恢复暗淡
- 显示内容：`Shift+↑/↓:nav  Enter:detail  /:search  Shift+V:code  Shift+U:cursor  Shift+A:antigrav  Shift+O:open  Shift+Y:yank  Shift+R:rescan`

**涉及文件**：
- `src/blink/tui/app.py` — `_build_key_bindings()` 所有绑定加 `s-` 前缀；删除 `j`/`k`/`e`/`t`/`q` 绑定；`_footer_text()` 改为暗淡样式
- `src/blink/tui/repo_list.py` — 如有内部按键处理需同步

### 3.2 搜索输入隔离

**现状**：搜索聚焦后，部分按键仍可能触发其他操作。

**改为**：
- 按 `/` 进入搜索输入态，**搜索输入框此时才显示**（默认隐藏，仅显示搜索前缀 `/`）
- 输入态下实时过滤（保持现有 `_on_search_change` 逻辑）
- 输入态下 **只响应以下按键**：

| 按键 | 行为 |
|------|------|
| 可打印字符 | 输入到搜索 buffer |
| `Backspace` | 删除字符 |
| `Enter` | **隐藏输入框，保留当前过滤结果**（不清空搜索） |
| `Esc` / `Ctrl+C` | 退出输入态并**清空搜索**，显示全部仓库 |

- 输入态下所有其他快捷键（包括 Shift 门控键）均被屏蔽
- Enter 退出后，搜索前缀 `/` 旁显示当前搜索词（只读），提示用户处于过滤状态
- 再次按 `/` 重新显示输入框，恢复之前的搜索词继续编辑

**搜索栏布局变化**：

```
默认（未搜索）：      /                   ← 只有前缀
搜索输入态：          / [search input]    ← 前缀 + 输入框
Enter 退出后：        / keyword           ← 前缀 + 当前搜索词（只读）
```

**实现思路**：
- 新增 `_search_active: bool` 标记搜索输入态
- 搜索输入框的 Window 通过 `Condition` 控制高度（0 或 1）
- 搜索退出态下只读显示当前搜索词
- 所有非搜索按键加 `filter=Condition(lambda: not self._search_active)`

**涉及文件**：
- `src/blink/tui/app.py` — 搜索状态管理、按键 filter、布局变化
- `src/blink/tui/search.py` — 暴露 focused 状态，支持只读显示

### 3.3 双击 Ctrl+C 退出

**现状**：`q` 退出，`Esc` 退出（无搜索/编辑时）。

**改为**：
- **移除 `q` 退出快捷键**
- **`Esc` 不再退出程序**，仅用于：取消搜索、退出编辑态、详情视图返回列表
- 新机制：**连续两次 Ctrl+C** 退出程序

**Ctrl+C 优先级链**（每层只消费一次，下层不再触发）：

```
1. 编辑态（别名/描述/标签编辑） → 退出编辑态，停留在当前视图
2. 搜索输入态                  → 退出输入态，清空搜索
3. 详情视图                    → 返回列表视图
4. 列表视图                    → 第一次：状态栏提示"再按一次 Ctrl+C 退出程序"
                                 第二次（2秒内）：退出程序
```

- 列表视图下第一次 Ctrl+C：状态栏显示 `再按一次 Ctrl+C 退出程序`，启动 2 秒窗口
- 2 秒内再按 Ctrl+C → 退出程序
- 超时未按 → 状态栏恢复，需重新双击
- `Esc` 在列表视图下：如果有搜索则清空搜索，否则无操作（不退出）

**实现**：
- 新增 `_last_ctrl_c: float` 记录上次 Ctrl+C 时间戳
- Ctrl+C handler 按优先级链逐层检查并消费
- `Esc` handler 简化为只处理取消操作

**涉及文件**：
- `src/blink/tui/app.py` — 移除 `q` 绑定，重写 `escape` 和新增 `c-c` 逻辑

## 列表视图新布局

```
┌─────────────────────────────────────────────────┐
│ /                                 ← 搜索前缀     │
│─────────────────────────────────────────────────│
│   ▸ alias (name) [tag]  ┐        ┐              │
│     /path/to/repo       ┘ 列表项 ┘ ← 项目列表   │
│─────────────────────────────────────────────────│
│ 42 repos                           ← 状态栏      │
│ Shift+↑/↓:nav  Enter:detail  …    ← 快捷键栏（暗淡）
└─────────────────────────────────────────────────┘
```

- 搜索输入框默认隐藏，按 `/` 后展开
- 所有操作键需要 Shift
- Enter 直接进入详情视图（不需要 Shift）
