# 窄终端视图切换方案

## 背景

当前 TUI 在终端宽度 < 80（`NARROW_THRESHOLD`）时隐藏右侧详情面板，但存在两个问题：

1. **阈值偏低**：80~110 之间双栏并排时列表被压到 min=25，详情空间也不够，双方体验都差
2. **窄窗口无详情**：详情面板直接消失，用户完全看不到选中仓库的元信息和操作入口

## 方案

将宽度阈值从 80 提升到 110，并引入「列表视图 / 详情视图」的全屏切换模式。

### 宽度分档

| 终端宽度 | 交互模式 | 布局 |
|----------|---------|------|
| ≥ 110 | 双栏并排 | 左列表 + 右详情，`→`/`←` 切焦点 |
| < 110 | 单视图切换（新增） | 同一时间只显示列表或详情，`→`/`←` 切换 |

### 单视图切换行为（宽度 < 110）

**列表视图 → 详情视图：**
- 按 `→` 键：列表隐藏，详情面板全屏展示，焦点移到详情
- 详情内容展示当前选中仓库的完整信息（Metadata / Actions / Local Markers 三区）

**详情视图 → 列表视图：**
- 按 `←` 键：详情隐藏，列表全屏展示，焦点移到列表
- 按 `Escape` 键：同上

**列表视图中的操作：**
- `↑` / `↓`：正常上下移动选中项
- 其他快捷键（`!` `@` `#` `$` `%` `^` `&` `*` `R` `L`）：保持现有行为不变
- 操作完成后留在列表视图

**详情视图中的操作：**
- `↑` / `↓` / `Shift+↑` / `Shift+↓`：行内导航和分组跳转（现有行为）
- `Enter`：执行当前高亮 action（现有行为）
- 编辑模式（tag/description）：保持现有行为

**搜索：**
- `/` 触发搜索时自动切回列表视图
- 搜索完成后留在列表视图

### 视图状态

新增 `_view_mode` 状态（`"list"` / `"detail"`），仅在窄模式（< 110）下生效。宽模式下忽略此状态，保持现有双栏行为。

### 终端 resize

- 从宽 → 窄：如果当前焦点在详情，自动切到详情全屏视图；否则留在列表
- 从窄 → 宽：恢复双栏布局，焦点保留在当前所在面板

## 影响范围

| 文件 | 改动 |
|------|------|
| `src/tui/key_bindings.py` | 删除 `Tab` 快捷键绑定（L135-L142）；`→` 在列表焦点时若窄模式则切到详情全屏；`←` 在详情焦点时若窄模式则切回列表全屏 |
| `src/tui/layout.py` | `NARROW_THRESHOLD` 80 → 110；`detail_visible` 条件逻辑增加窄模式视图切换判断；列表面板在窄模式详情视图时也要隐藏 |
| `src/tui/app.py` | 新增 `_view_mode` 属性（`"list"` / `"detail"`）；可能需要调整 `_set_focus` 方法 |
| `docs/agents/ui-spec.md` | 移除 Tab 快捷键说明；更新窄终端交互说明和快捷键表 |

### 移除 Tab 快捷键

本方案同时移除现有的 `Tab` 焦点切换快捷键。理由：

- 宽模式：`→`/`←` 已经覆盖焦点切换，`Tab` 多余
- 窄模式：`→`/`←` 负责视图切换，`Tab` 语义不清晰
- 减少按键认知负担，一套 `→`/`←` 规则适用于所有宽度
