$ARGUMENTS

## Overview

撰写方案文档，存储到 `docs/plan/` 目录，不实施代码改动。

## 执行规则

1. **解析用户输入**：`$ARGUMENTS` 为方案标题（必填）

2. **确定编号**：扫描 `docs/plan/` 下所有 `plan{N}-*.md` 文件，取最大编号 +1。若无匹配文件则从 1 开始

3. **生成文件名**：`plan{N}-{slug}.md`
   - `slug` 由标题生成：中英文、数字保留，空格和特殊字符替换为 `-`，截断至 80 字符，去除首尾 `-`
   - 示例：标题 `重构 Review 模块` → 文件名 `plan8-重构-Review-模块.md`

4. **写入模板**：创建文件并填入以下结构

```markdown
# {标题}

## 背景


## 方案


## 影响范围


## 待定

```

5. **根据用户输入补充内容**：如果用户在标题之外还提供了更多描述（如具体需求、约束条件等），将其填入模板的对应章节

## 注意事项

- 不修改任何代码文件，仅创建 markdown
- 如果 `docs/plan/` 目录不存在，自动创建
- 文件创建后告知用户文件路径
